Everything you need to take your context with you

Switching editors or laptops shouldn't mean starting every conversation from scratch.

Transfer between tools

Copy a session from Cursor into Claude Code, Codex or Copilot CLI in one step. MoveZ converts each tool's format for you.

Move to a new machine

Export to a portable .cbz bundle and import it anywhere. Project paths are remapped, so D:\Projects becomes ~/work.

Encrypted end to end

Bundles and sync payloads are sealed with AES-256-GCM before they leave your machine. Your key never does.

Self-hosted sync

Run your own sync server and push or pull sessions between machines. It only ever stores ciphertext.

Desktop, CLI or editor

A desktop app for Windows, macOS and Linux, a single-file CLI, and a VS Code / Cursor extension. Use whichever fits.

Project config comes too

Optionally bundle CLAUDE.md, AGENTS.md, .cursorrules and .mcp.json so a new machine is ready to go.

How it works

Three steps, in the app or on the command line.

  1. 1

    Pick your sessions

    MoveZ finds the conversations every installed AI tool has stored on this machine.

  2. 2

    Transfer or bundle

    Send them straight to another tool, or pack them into an encrypted .cbz for another machine.

  3. 3

    Keep working

    Open the target tool — the full conversation history is there, under the right project.

terminal
# copy Cursor sessions into Claude Code
$ movez transfer --from=cursor --to=claude-code
Transferred 2 session(s) from cursor to claude-code

# back up to an encrypted bundle
$ movez export --tool=claude-code --output=work.cbz --encrypt
Exported 3 session(s) to: work.cbz

# restore on the new laptop, fixing paths
$ movez key:import --file=movez.key
$ movez import --input=work.cbz --tool=claude-code \
    --from-path="D:/Projects" --to-path="~/work"
Imported 3 session(s) to claude-code

Local-first. Private by design.

Your conversations are yours. MoveZ runs on your machine and talks to nothing you didn't configure.

  • No telemetry, no accounts. MoveZ makes no network calls except to a sync server you run yourself.
  • AES-256-GCM encryption. Bundles and sync payloads are encrypted client-side; the server stores ciphertext only.
  • Your key stays with you. It lives at ~/.movez/key and only moves when you run movez key:export.
  • Open source. MIT-licensed, with tests for every format it reads and writes.

Questions

Does the AI remember the conversation after a transfer?

You get the full conversation history in the target tool. Cursor also keeps an internal model state that can't be recreated, so there the history is visible but the model won't automatically pick it up — start a new chat and reference the old one.

Do I need a server?

No. Transfers and .cbz bundles work entirely offline. The self-hosted sync server is optional, for pushing and pulling between machines without copying files.

How do I move my encryption key to another machine?

Run movez key:export on the first machine and movez key:import on the next, or pipe one into the other over SSH. movez key:fingerprint confirms both machines hold the same key.

Is it free?

Yes. MoveZ is open source under the MIT license.
